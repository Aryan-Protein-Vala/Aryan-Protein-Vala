### What I Built

- **[Astral-Offline](https://github.com/Aryan-Protein-Vala/Astral-Offline)** — Air-gapped BLE payment & DTN mesh: Rust crypto core (`p256`, `chacha20poly1305`, `blake3`) bridged to native Swift & Kotlin via UniFFI.
- **[AetherNet](https://github.com/Aryan-Protein-Vala/AetherNet)** — Zero-copy P2P data logistics engine in Go using `syscall.Mmap`, QUIC stream multiplexing, and mDNS local peer discovery.
- **[MyloOS](https://github.com/Aryan-Protein-Vala/MyloOS)** — Cross-platform Rust/Tauri + Next.js desktop operator using ScreenCaptureKit / Windows Graphics Capture and native `CGEvent` / `SendInput` injection.
